# Security policy

This provider is a proof of concept. Security fixes are developed against
the current `main` branch and carried to `beta` when applicable. Upgrade to
the latest release containing a fix; older versions do not have a separate
maintenance commitment.

Report suspected vulnerabilities privately using
[Report a vulnerability](https://github.com/elva-labs/terraform-provider-vew/security/advisories/new).
Include affected versions, reproduction steps, impact, and a proposed fix
if available. Remove credentials and sensitive customer data from examples.
Please keep exploit details out of public issues and pull requests until
maintainers have coordinated a fix and disclosure.

Maintainers review reports and coordinate fixes through GitHub's private
security advisories. There is no guaranteed response time.
