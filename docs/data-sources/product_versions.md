# vew_product_versions data source

Lists the versions of a product with the stages each version is released to
and their aggregated status. Use it to pick a version to promote with
`vew_product_version_promotion`.

Permission: project assignment and `clients/publishing/version.read`. The
provider must be configured with `publishing_api_url` or
`VEW_PUBLISHING_API_URL`.

## Selectors

| Attribute | Type | Description |
| --- | --- | --- |
| `project_id` | string | Required VEW project identifier. |
| `product_id` | string | Required VEW product identifier. |

## Computed attributes

`versions` is a list of objects with `version_id`, `version_name`,
`version_type`, and `stages`, a list of objects with `stage` (`DEV`, `QA`, or
`PROD`) and `status`.

```hcl
data "vew_product_versions" "workbench" {
  project_id = var.project_id
  product_id = var.product_id
}

output "dev_version_ids" {
  value = [
    for version in data.vew_product_versions.workbench.versions : version.version_id
    if contains([for stage in version.stages : stage.stage], "DEV")
  ]
}
```
