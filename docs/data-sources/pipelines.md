# vew_pipelines data source

Lists all pipelines returned for a project. Results are sorted by ascending
`pipeline_id`; an empty result is successful. Terminal pipelines are included
when VEW returns them.

Permission: project assignment and `clients/packaging/pipeline.read`.

## Selectors

| Attribute | Type | Description |
| --- | --- | --- |
| `project_id` | string | Required VEW project identifier. |

## Computed attributes

`pipelines` is a list of objects with `project_id`, `pipeline_id`, `name`,
`description`, `recipe_id`, `recipe_name`, `recipe_version_id`,
`recipe_version_name`, `build_instance_types`, `schedule`, nullable
`product_id`, `status`, nullable `distribution_config_arn`,
`infrastructure_config_arn`, `pipeline_arn`, `created_at`, `created_by`,
`updated_at`, and `updated_by`.

```hcl
data "vew_pipelines" "project" {
  project_id = var.project_id
}

output "pipeline_ids" {
  value = [for pipeline in data.vew_pipelines.project.pipelines : pipeline.pipeline_id]
}
```
