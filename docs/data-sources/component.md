# vew_component data source

Reads one existing component in a project. Archived components remain
readable when VEW returns them; no component is imported or modified.

Permission: project assignment and `clients/packaging/component.read`.

## Selectors

| Attribute | Type | Description |
| --- | --- | --- |
| `project_id` | string | Required VEW project identifier. |
| `component_id` | string | Required exact component identifier. |

## Computed attributes

`name`, `description`, `platform`, `supported_architectures`,
`supported_os_versions`, `status`, `created_at`, `created_by`, `updated_at`,
and `updated_by` reflect the readable VEW object. A 404 is an error.

```hcl
data "vew_component" "existing" {
  project_id   = var.project_id
  component_id = var.component_id
}

output "component_platform" {
  value = data.vew_component.existing.platform
}
```
