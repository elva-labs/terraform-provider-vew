# vew_recipe (Resource)

Manages a project recipe. Terraform updates its description in place and
archives it when the resource is deleted. Changes to its identifying and
platform fields require replacement.

## Example Usage

```terraform
resource "vew_recipe" "example" {
  project_id   = "project-example"
  name         = "example-recipe"
  description  = "Managed by Terraform"
  platform     = "Linux"
  architecture = "amd64"
  os_version   = "Ubuntu 24"
}
```
