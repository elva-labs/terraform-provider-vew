# vew_technology (Resource)

Manages a project technology through the Projects API. The provider must be
configured with `projects_api_url` or `VEW_PROJECTS_API_URL`; the caller needs
an active assignment to the project and the `clients/projects/technology.read`
and `clients/projects/technology.write` scopes. Changes to `project_id` require
replacement. Changes to `name` and `description` update the existing
technology in place. Terraform deletes the technology when the resource is
removed.

VEW retains project account references after an account assignment is
deactivated. If any retained account still references a technology, VEW rejects
technology deletion. Resolve that association through VEW before deleting the
technology. Use `lifecycle { prevent_destroy = true }` when Terraform should
refuse planned deletion or replacement.

## Example Usage

```terraform
terraform {
  required_providers {
    vew = {
      source = "elva-labs/vew"
    }
  }
}

provider "vew" {
  api_url          = "https://api.example.invalid/clients/packaging/v1"
  projects_api_url = "https://api.example.invalid/clients/projects/v1"
}

resource "vew_technology" "example" {
  project_id   = "project-example"
  name         = "example-technology"
  description  = "Managed by Terraform"

  lifecycle {
    prevent_destroy = true
  }
}
```
