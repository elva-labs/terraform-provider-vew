# vew_project_workbench_lifecycle (Resource)

Sets when a project's workbenches stop and what their owners may change on
their own workbenches. Unset `idle_stop_minutes`, `nightly_stop` and
`weekend_stop` fall back to the deployment's defaults. `always_on` bypasses
every stop. The `allow_user_*` switches decide whether owners may turn off
the nightly stop or set their own idle timeout, within
`user_idle_timeout_min_minutes` and `user_idle_timeout_max_minutes`
(10-1440 minutes). VEW enforces these bounds on the server; it never starts a
workbench by itself.

Set `projects_api_url` and grant the provider client
`clients/projects/program.read` and `clients/projects/program.write`, plus an
active assignment to the project. The policy is a singleton per project:
create and update replace the whole policy, and destroy returns the project
to the deployment's defaults.

## Example Usage

```terraform
terraform {
  required_providers {
    vew = {
      source = "elva-labs/vew"
    }
  }
}

provider "vew" {
  api_url          = "https://api.example.invalid/clients/packaging/v1"
  projects_api_url = "https://api.example.invalid/clients/projects"
}

resource "vew_project_workbench_lifecycle" "example" {
  project_id = "project-example"

  # Unset: the deployment's defaults for the idle and nightly stops.
  weekend_stop = true

  allow_user_disable_nightly_stop = true
  allow_user_idle_timeout         = true
  user_idle_timeout_min_minutes   = 10
  user_idle_timeout_max_minutes   = 480
}
```

## Schema

### Required

- `project_id` (String)

### Optional

- `allow_user_disable_nightly_stop` (Boolean) Owners may turn off the nightly stop on their own workbenches.
- `allow_user_idle_timeout` (Boolean) Owners may set their own idle timeout within the bounds below.
- `always_on` (Boolean) Workbenches bypass idle, nightly and weekend stops.
- `idle_stop_minutes` (Number) Stop after this many idle minutes (10-1440). Unset uses the deployment's default.
- `nightly_stop` (Boolean) Stop running workbenches nightly. Unset uses the deployment's default.
- `user_idle_timeout_max_minutes` (Number) Highest idle timeout an owner may set (10-1440).
- `user_idle_timeout_min_minutes` (Number) Lowest idle timeout an owner may set (10-1440).
- `weekend_stop` (Boolean) Stop running workbenches at the weekend. Unset uses the deployment's default.

### Read-Only

- `id` (String) The ID of this resource.
