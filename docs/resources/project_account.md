# vew_project_account (Resource)

Manages an AWS account assignment in a VEW project through the Projects API.
Configure `projects_api_url` or `VEW_PROJECTS_API_URL`. The service client
needs an active assignment to the project and both
`clients/projects/account.read` and `clients/projects/account.write` scopes.

Create and update start asynchronous AWS account onboarding or re-onboarding.
Terraform polls VEW until the operation completes, with a two-hour timeout by
default. Set `timeouts.create` or `timeouts.update` to change that limit.
After deactivation, creating the assignment again in the same project for the
same AWS account asks VEW to reactivate it. VEW reuses the inactive assignment's
internal ID and starts onboarding again, which may make further AWS changes.

Changing `project_id` or `aws_account_id` requires replacement. Changes to
`name`, `description`, `account_type`, `technology_id`, `stage`, or `region`
update the existing assignment in place and start re-onboarding.

Deleting this resource deactivates the VEW project assignment. It does not
remove the AWS account, undo onboarding, or perform AWS offboarding. The account
association remains retained by VEW and can keep its technology referenced.
Use `lifecycle { prevent_destroy = true }` to block deletion or replacement
plans until the assignment's lifecycle has been reviewed.

Onboarding makes real changes in the AWS account and can incur charges. Only
manage an explicitly approved disposable account with credentials authorized
for its onboarding. Never use a production account as a Terraform acceptance
fixture.

## Example Usage

```terraform
terraform {
  required_providers {
    vew = {
      source = "elva-labs/vew"
    }
  }
}

variable "project_id" {
  description = "VEW project that owns this account assignment."
  type        = string
}

variable "aws_account_id" {
  description = "12-digit AWS account ID explicitly approved for VEW onboarding."
  type        = string
}

variable "technology_id" {
  description = "ID of an existing technology in the VEW project."
  type        = string
}

provider "vew" {
  api_url          = "https://api.example.invalid/clients/packaging/v1"
  projects_api_url = "https://api.example.invalid/clients/projects/v1"
}

resource "vew_project_account" "example" {
  project_id     = var.project_id
  aws_account_id = var.aws_account_id
  account_type   = "USER"
  name           = "example-development-account"
  description    = "Managed by Terraform"
  technology_id  = var.technology_id
  stage          = "dev"
  region         = "eu-west-1"

  timeouts = {
    create = "2h"
    update = "2h"
  }

  lifecycle {
    prevent_destroy = true
  }
}
```
