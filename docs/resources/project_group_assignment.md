# vew_project_group_assignment (Resource)

Grants a nonempty set of VEW project roles to one Entra group object ID. Set
`projects_api_url` and grant the provider client
`clients/projects/group_assignment.read` and
`clients/projects/group_assignment.write`, plus an active assignment to the
project. The group ID must be a UUID and is canonicalized to lowercase. Group
names and members are not part of the resource identity.

VEW combines roles from every group in a user's validated login claim with
that user's direct assignment. Changing group membership requires no Terraform
update. The human authorizer has TTL zero and reads trusted Cognito UserInfo on
each request. Membership changes appear after a refreshed login updates the
Cognito group attribute; an older token may carry prior identity until expiry.
A missing or malformed claim
grants no group-derived roles.

The login path's `OIDCGroupIdClaim` (default `groups`) must carry actual Entra
group UUIDs within the Cognito custom attribute limit. Display names and
overage pointers (`_claim_names` or `hasgroups`) grant no group roles. VEW does
not resolve them through Microsoft Graph.

Mapping changes project asynchronously to Authorization. Monotonic versions
and deletion tombstones prevent delayed event replay from restoring older
grants. A missed event may take up to seven days plus the reconciliation job
duration to recover: the scheduled job currently runs Saturdays at 08:00 UTC
and must succeed. Monitor event delivery and that job. Membership removal from
a refreshed trusted profile is independent of mapping projection.

Roles update in place; refresh detects remote edits. Destroy removes only the
project-to-group mapping. It does not change Entra group members or direct
assignments.

## Example Usage

```terraform
resource "vew_project_group_assignment" "engineers" {
  project_id = vew_project.example.id
  group_id   = "01234567-89ab-cdef-0123-456789abcdef"
  roles      = ["PLATFORM_USER"]
  group_name = "vew-engineers" # optional label shown in the portal
}
```
