# vew_project_management (Resource)

Marks a project as managed by an external tool, typically the Terraform
configuration that also declares the project. While the mark is set, VEW
refuses configuration changes made by signed-in users (program settings,
accounts, users and groups, components, recipes, pipelines, products,
versions and promotions) and tells them to change `source` instead. Using
workbenches (launch, start, stop, connect, update and remove) stays open to
users, and the provider's own service calls are not affected.

Set `projects_api_url` and grant the provider client
`clients/projects/program.read` and `clients/projects/program.write`, plus an
active assignment to the project. The mark is a singleton per project: create
and update both replace it, and destroy removes it, which hands the project
back to the portal. A new mark reaches the authorizer asynchronously.

## Example Usage

```terraform
terraform {
  required_providers {
    vew = {
      source = "elva-labs/vew"
    }
  }
}

provider "vew" {
  api_url          = "https://api.example.invalid/clients/packaging/v1"
  projects_api_url = "https://api.example.invalid/clients/projects"
}

resource "vew_project_management" "example" {
  project_id = "project-example"
  source     = "example-org/vew-config programs/example"
}
```
