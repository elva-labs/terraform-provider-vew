# vew_project (Resource)

Creates a project through the Projects S2S API. Set `projects_api_url` or
`VEW_PROJECTS_API_URL`. The service client needs
`clients/projects/program.write` to create or change a project and
`clients/projects/program.read` to refresh it. Project creation automatically
grants the creating service client an active assignment to the new project.
Reads and updates of an existing project also require that active assignment.

The project ID is stable. Name, nullable description, and active status update
in place. Import and refresh use exact project reads, including for inactive
projects. The create request uses a persisted idempotency key so a repeated
request can recover the same project after a lost response.

Destroy **deactivates** the project and removes it from Terraform state. VEW
retains the project ID, history, and assignments. Import the project again to
manage it, or set `is_active = true` to reactivate an imported inactive project.
Review dependents before destroying a project.

## Example Usage

```terraform
resource "vew_project" "example" {
  name        = "example-project"
  description = "Managed by Terraform"
  is_active   = true
}
```

### Optional

- `description` (String)
- `experience` (String) What the project's members get in the portal: "full", or "workbench-only" (members other than admins only see and launch their workbenches, from released versions). Unset keeps the current value; new projects are full.
