# vew_product_version_promotion (Resource)

Promotes a product version to a stage (`DEV`, `QA`, or `PROD`) through the
Publishing API, which publishes it to the stage's accounts. Every image a
pipeline builds for a product adds a version in `DEV`; promoting it to `QA` or
`PROD` makes it available to the users who may use that stage.

The provider must be configured with `publishing_api_url` or
`VEW_PUBLISHING_API_URL`; the caller needs an active assignment to the project
and the `clients/publishing/version.read` and
`clients/publishing/version.promote` scopes. VEW applies the same rules as in
the portal: every distribution of the version must be created, `PROD` accepts
only release candidates (the version then gets its release name, for example
`1.0.0-rc.2` becomes `1.0.0`), and the stage needs an onboarded account.

Terraform waits until the version is published in every account of the stage
(one hour by default, configurable with `timeouts.create`). A promotion that is
still publishing when the timeout expires stays in state and is reconciled by
the next apply. All arguments force replacement.

Destroying the resource only removes it from Terraform: VEW does not undo a
release. Retire a version in VEW to withdraw it.

## Example Usage

```terraform
terraform {
  required_providers {
    vew = {
      source = "elva-labs/vew"
    }
  }
}

provider "vew" {
  api_url            = "https://api.example.invalid/clients/packaging/v1"
  publishing_api_url = "https://api.example.invalid/clients/publishing"
}

# Release a tested DEV version of a product to its users.
resource "vew_product_version_promotion" "example" {
  project_id = "project-example"
  product_id = "prod-example"
  version_id = "vers-example"
  stage      = "PROD"
}
```
